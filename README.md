# 🏃‍♂️ RunnerGo 🚄

Welcome to the tracks! **RunnerGo** is a fast-paced, high-energy 3D endless runner game inspired by the legendary *Subway Surfers*. Built completely from scratch using the **GDevelop** engine, this project takes classic lane-switching mechanics and packs them into a lightweight, arcade-style experience.

---

## 🎮 The Mission
Dash down the never-ending railway, dodge oncoming trains, clear hazardous barriers, and see how long you can survive the ultimate speed test. 

### Current Feature Roadmap:
* 🛣️ **Endless Texture Loop:** An infinite scrolling track that keeps the momentum going forever.
* ⚡ **3-Lane Grid Snap:** Quick, responsive lane-switching layout to cut through tight spaces.
* 📦 **Procedural Obstacles:** Randomly generated blockades dropped directly onto the field using automated scene timers.

---

## 🕹️ Controls & Navigation

Get your fingers ready on the keyboard:
* ⬅️ **Left Arrow Key** — Fast-slide into the left lane
* ➡️ **Right Arrow Key** — Fast-slide into the right lane
* ⬆️  **Spacebar** — Leap clear over low-lying barricades
